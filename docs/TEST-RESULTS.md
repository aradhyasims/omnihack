## Bugs found and fixed during verification

1. **Authorization:** competition owners could approve their own results. Approval is now restricted to organization owners and admins (tested).
2. **Status codes:** a `loading.tsx` boundary made private drafts return 200 instead of 404. Fixed.
3. **UX:** forms lost user input after validation errors (React 19 form reset). Fixed.
4. **Locked-stage settings:** saving a started stage could have disabled all submission fields. Fixed.
5. **Logo:** SVG gradients broke when the first copy was hidden. Switched to solid fills.
6. **Banner and logo uploads:** the storage key pattern rejected `.` in file names, so every banner or logo upload would have failed. Fixed (the key pattern still blocks `..`).
