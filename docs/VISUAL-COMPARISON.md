# Visual comparison: reference vs OmniHack

**Method:** The reference site (https://hackculture.io/) was inspected through its publicly served markup to record structure and hierarchy. Screenshots of the reference were **not** captured, so this is a structural comparison, not a pixel comparison. No logos, imagery, copy or code from the reference were reused. OmniHack screenshots were captured with Playwright (`scripts/screenshots.mjs`) at 1366px and 390px and are in `docs/screenshots/`.

| Reference pattern (observed)                                               | OmniHack implementation                                                                                                                         | Screenshot                                   |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| Header: logo plus grouped navigation (Programs / Offerings / Get involved) | Sticky translucent header; "Explore" and "For organizers" dropdowns with icon descriptions; FAQ, About; "Host a competition" CTA; mobile drawer | `home-desktop.png`, `home-mobile.png`        |
| Large two-level hero headline with tagline and value line                  | Dark ink hero, gradient headline "Where ideas become winning projects.", two CTAs (Explore / Host)                                              | `home-desktop.png`                           |
| Audience toggle (corporates / innovators)                                  | Separate "For organizers" / "For participants" benefit panels and a dedicated `/host` page                                                      | `home-desktop.png`                           |
| Client-logo strip                                                          | **Omitted on purpose:** no customers are claimed. Replaced by a product "competition pipeline" visual                                           | `home-desktop.png`                           |
| Six-card offerings grid                                                    | Featured ideathon and hackathon competition cards from live data, plus a four-step "How OmniHack works"                                         | `home-desktop.png`, `competitions.png`       |
| Impact numerals (four large figures)                                       | Real database counts only (non-demo); falls back to capability facts                                                                            | `home-desktop.png`                           |
| Testimonials carousel, partner marquee                                     | **Omitted** until authorized testimonials and confirmed sponsors exist                                                                          | —                                            |
| Closing CTA band                                                           | Gradient CTA band "Your next competition starts here."                                                                                          | `home-desktop.png`                           |
| Four-column footer with contact and legal bar                              | Brand, Platform, Resources and Company columns; contact email; privacy and terms; social links only when configured                             | `home-desktop.png`                           |
| Program listings / event pages                                             | `/competitions` with filters and cards; detailed event pages with sticky key-facts sidebar and in-page navigation                               | `competitions.png`, `competition-detail.png` |

Beyond the reference's marketing scope, OmniHack adds the full application UI: wizard (`wizard-eligibility.png`), stage engine (`organizer-stages.png`), judging and ranking (`judging.png`), analytics (`analytics.png`), public results (`results.png`) and certificate verification (`certificate-verification.png`).

**Responsive check:** the homepage at 390px (`home-mobile.png`) stacks to a single column, the hero CTAs stay above the fold, and cards keep a 16px gutter with no horizontal scrolling. The Playwright `mobile` project exercised the participant flow at this size.
